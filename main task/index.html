About the Store Experience

NEXA Commerce is a modern storefront built to feel like a real online shopping destination while staying fully local to your browser. The shop keeps products, users, carts, orders, statuses, refunds, and admin-added inventory in localStorage, so the experience survives a page refresh without a server.

The checkout flow is designed around clarity. Customers can review subtotal, delivery fee, platform fee, coupon savings, COD fee, and total before placing an order. UPI payments show a QR code, card payments collect card details, and cash on delivery adds a small handling charge.

The admin dashboard is connected directly to the customer store. When an admin adds a new product, it appears in the catalog and new arrivals. When an order status changes, the customer-facing order record is updated. Cancelled orders automatically create refund details with a refund ID, refund amount, and initiation time.

The goal is a smooth store experience: fast browsing, clean category chips, visible discounts, practical order management, and an operations dashboard that feels calm enough to use every day.
